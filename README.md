# 图片处理工具 (image-tool)

基于 OpenCV 的命令行图片处理工具，支持读取图片信息、缩放、裁剪、旋转、翻转、灰度化、格式转换。

## 项目介绍

- 程序做什么：读取图片基础信息，并对图片进行常见的简单编辑。
- 支持功能：读取信息、缩放、裁剪、旋转(90/180/270)、翻转(水平/垂直)、灰度化、格式转换。
- 程序形式：命令行(CLI)工具。
